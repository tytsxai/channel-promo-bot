# 用户手册

## 简介

Telegram 互推机器人是一个帮助频道主进行互相推广的工具。通过提交您的频道，经管理员审核后，您的频道将与其他参与者一起出现在每日推送的互推文案中。

---

## 快速开始

### 第一步：启动机器人

在 Telegram 中搜索机器人并发送 `/start` 命令。

### 第二步：提交频道

发送命令：
```
/submit @your_channel
```
或
```
/submit https://t.me/your_channel
```

### 第三步：等待审核

提交后请耐心等待管理员审核，审核通过后您的频道将加入互推列表。

---

## 命令详解

### /start

显示欢迎消息和基本使用说明。

**示例输出：**
```
👋 欢迎使用互推机器人！

发送 /submit <频道链接> 提交你的频道
发送 /help 查看详细帮助
```

### /help

显示详细的帮助信息，包括所有命令和参与条件。

### /submit

提交频道参与互推。

**用法：**
```
/submit @channel_username
/submit https://t.me/channel_username
```

**参与条件：**
- 频道必须为公开频道
- 成员数需达到最低要求（默认 700 人）

**可能的响应：**

| 情况 | 响应 |
|------|------|
| 成功 | 频道提交成功，等待审核 |
| 格式错误 | 无效的频道链接格式 |
| 频道不存在 | 无法获取频道信息 |
| 成员不足 | 成员数不足最低要求 |
| 重复提交 | 该频道已提交过 |

### /list

查看所有已通过审核的频道列表，按分类显示。

---

## 常见问题

### Q: 提交后多久能通过审核？

A: 审核时间取决于管理员，通常在 24 小时内完成。

### Q: 互推文案什么时候发送？

A: 每天固定时间发送（默认北京时间 13:00）。

### Q: 我的频道被拒绝了怎么办？

A: 请确保频道符合参与条件后重新提交。

### Q: 如何退出互推？

A: 请联系管理员处理。

---

## 管理员指南

### /pending

查看待审核频道列表（分页显示）。

**操作按钮：**
- ✅ - 通过审核
- ❌ - 拒绝
- ⬅️/➡️ - 翻页

### /stats

查看系统统计信息，包括已通过和待审核频道数量。
